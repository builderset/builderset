# Code of conduct

Builderset follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its full text applies to everyone who takes part — in issues, pull requests,
discussions and any other space of the project.

In short:

- Be kind and patient, and assume good intent. Many contributors write in a
  language that is not their first.
- Criticise code and ideas, never people.
- No harassment, insults, sexualised language or imagery, or publishing anyone's
  private information.

## Reporting

Report behaviour that breaks this code to the maintainers privately, through the
repository's **Security** tab → **Report a vulnerability** (it reaches only the
maintainers), until the project has its own contact address.
