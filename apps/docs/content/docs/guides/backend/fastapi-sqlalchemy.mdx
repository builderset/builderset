---
title: 'FastAPI and SQLAlchemy'
description: The email editor's backend in Python — FastAPI routes over Postgres with SQLAlchemy and Alembic, checked and rendered by the builderset package, with who did what, soft delete, revisions and an activity log. About 30 minutes.
---

At the end a Python server stores the templates, refuses what the editor would
refuse — with the same issue codes — and renders the email to send, byte for byte
as the Node renderer does. Every row records who made it, changed it and deleted it,
and when; deleting is a soft delete; each template keeps its revisions and an
activity log, as the [data model](/docs/guides/backend/data-model) describes. Every
file is from
[`examples/backends/fastapi-sqlalchemy`](https://github.com/builderset/builderset/tree/development/examples/backends/fastapi-sqlalchemy),
tested against a real Postgres on each change. The Python package's install is in
[Python](/docs/reference/python).

_This page describes Builderset 0.5.1._
