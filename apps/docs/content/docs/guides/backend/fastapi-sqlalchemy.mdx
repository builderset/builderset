title: 'FastAPI and SQLAlchemy'
description: The email editor's backend in Python — FastAPI routes over Postgres with SQLAlchemy and Alembic, checked and rendered by the builderset package. About 20 minutes.
---

At the end a Python server stores the templates, refuses what the editor would
refuse — with the same issue codes — and renders the email to send, byte for byte
as the Node renderer does. Every file is from
[`examples/backends/fastapi-sqlalchemy`](https://github.com/builderset/builderset/tree/development/examples/backends/fastapi-sqlalchemy),
tested against a real Postgres on each change. The Python package's install is in
[Python](/docs/reference/python).

_This page describes Builderset 0.3.0._
