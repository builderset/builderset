The routes, the checks and the answers are the same as in
[Next.js and Drizzle](/docs/guides/backend/next-drizzle), which explains each step;
this page shows what Prisma changes. Every file is from
[`examples/backends/next-prisma`](https://github.com/builderset/builderset/tree/development/examples/backends/next-prisma),
tested against a real Postgres on each change.

_This page describes Builderset 0.4.0._
