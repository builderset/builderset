## Reading a stored article

`parseArticle(raw, registry)` checks the shape, runs the element migrations and
returns `{ ok, doc, issues, migrated }`; `checkArticle(doc, registry, { locales })`
returns every issue ([Issues](/docs/reference/issues)).

## The renderer

`ArticleRenderer`, `structuredData` and `jsonLdString` are in
`@builderset/article/render`. Every prop of the renderer is in
[Props](/docs/reference/props); how to use them is in
[Showing articles](/docs/guides/articles).
