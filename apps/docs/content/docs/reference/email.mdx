## Variables

A variable is a dotted path in double braces, optionally with a format:
`{{ recipient.name }}`, `{{ order.total | money }}`. There is no expression
language. An email type declares what a template may use; the system variables are
always there:

<include cwd lang="ts" meta='title="@builderset/email — EmailType"'>
  ../../packages/email/src/core/variables.ts#types
</include>

The formats:

<include cwd lang="ts" meta='title="@builderset/email — FORMATS"'>
  ../../packages/email/src/core/variables.ts#formats
</include>

Dates and numbers are formatted for `sq`, `en` and `de`, in the `Europe/Tirane`
time zone, in 0.3.0.
